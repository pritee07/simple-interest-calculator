# Simple Interest Calculator

A simple calculator to calculate simple interest.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

## Example

If the principal amount is ₹10,000, the rate of interest is 5%, and the time period is 2 years:

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

## Features

- Easy to use
- Calculates simple interest
- Takes principal, rate, and time as inputs
